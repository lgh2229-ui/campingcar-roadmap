# 웨이팅 고객접수 v2.0 — 설치 오류 수정

- 변경된 앱 ID: `kr.co.waitingprogram.kiosk` (기존 테스트앱 `kr.co.waitingprogram.pos`와 충돌 방지)
- 동일한 지속 보관 서명키를 빌드마다 복원하며 SHA-256 인증서 지문 검사
- Android 6.0 이상(최소 API 23) 설치 가능하도록 서명 방식 검증
- GitHub Actions에서 APK 설치/실행 에뮬레이터 검사 후 다운로드 파일 제공
- 저장된 매장 설정은 새 앱 ID로 인하여 최초 실행 시 매장 1회 선택
- 기존 테스트 APK는 기기에 남을 수 있으므로 제거 권장
- 화면 자동 맞춤 및 고객 등록 화면은 이전 v1의 기능 유지
- 카카오 알림톡 API 발송 연동은 공급사 승인된 템플릿과 발신 채널을 연결해야 실제 발송됨
- 매장 접수는 서버 운영자가 활성화하기 전까지 닫혀 있음

이 APK는 고정 테스트 인증서로 서명한 설치용 테스트 빌드로, Google Play 정식 배포용 인증서는 아닙니다.
