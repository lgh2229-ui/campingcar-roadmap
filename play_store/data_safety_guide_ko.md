# Google Play 데이터 보안 작성용 체크 초안

실제 출시 직전에 Play Console 질문 문구에 맞춰 다시 확인해야 합니다.

- 계정 정보: 아이디, 휴대폰 번호
- 위치: 사용자가 현재 위치/장소등록 기능을 사용할 때 정밀 위치 사용
- 사용자 제작 콘텐츠: 장소 정보, 장소사진, 검증리뷰
- 앱 활동: 저장한 장소
- 차량정보: 차량명/모델, 높이, 위생설비(개인식별정보로 분류되는지 Play Console 최신 질문에 따라 확인)
- 전송 암호화: HTTPS/TLS 사용
- 계정 삭제: 정식 출시 전에 앱 내 탈퇴 기능 및 서버 데이터 삭제 절차 추가 필요
- 광고: 현재 V2 소스에는 광고 SDK 없음

주의: 앱이 실제로 수집/공유하는 데이터와 Supabase/SMS 공급자의 처리방식을 기준으로 최종 답변해야 합니다.
